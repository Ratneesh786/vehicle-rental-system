Project Statement

Project Title

Vehicle Rental Portal

1. Problem Statement

Vehicle Rental is a widely-used service where customers usually seek assistance while looking for the desired

vehicle

check its availability,

get familiar with the rental cost,

and provide verification

documents before renting it.

However, this process might become complicated when people attempt to manage it manually.

The Vehicle Rental Portal is a Python-based console application, which aims to simplify the process of renting a vehicle.

It enables the user to choose a category of vehicles, check their availability, select the desired

vehicle from the shortlist, enter the number of days of renting, provide verification documents, and obtain the final receipt.

2. Scope of the Project

The current project scope includes the general features, which are required for the majority of vehicle rental services.

The main components of the system, which are implemented in the project, are the following:

Selecting a vehicle category;

Displaying available vehicles;

Displaying the name and rate per day;

Selecting a vehicle;

Checking the availability of a vehicle;

Entering the duration of renting;

Checking the correctness of the entered value (the number of days cannot be equal to zero or a negative number);

Providing verification document details;

Calculating the amount of money for renting a vehicle (Rate × Number of Days);

Adding a security deposit;

Updating the availability of a vehicle;

Printing the transaction receipt.

The current project scope does not include the database, a system of online payments, the customer account system, or a Graphical User Interface.

3. Target Users

The target users of the Vehicle Rental Portal include the following groups of individuals:

Custom ers

can check the availability of a vehicle, select the desired one, enter the number of days of renting, provide verification document details, and view the amount of money to pay for renting.

4. High-Level Features

The main features of the vehicle rental portal, which were implemented in the project, include:

Selecting a vehicle category.

The user should pick the category of vehicles, which he/she is interested in (for instance, a car, an SUV, or a bike).

Available Vehicle Display.

The system will display the list of available vehicles, which fit the selected category. It will also show the price per day of renting a vehicle.

Selecting a vehicle.

The user can enter the exact name of the desired vehicle. The system will check if it is available.

Rental duration.

The system will ask the user to enter the number of days, which he/she wants to rent the desired vehicle.

Document verification.

The system will prompt the user to provide verification document details. The input of the user will be checked to ensure that it is not blank. In case of an incorrect input, the user will be asked to enter the required information once again.
